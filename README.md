# Flappy Wiu

### Steps 

Create a new enviroment, install pygame-ce:
```
# 1. Create the virtual environment folder (named .venv)
python -m venv .venv

# 2. Activate it 
# On Windows (Command Prompt):
.venv\Scripts\activate.ps1

# 3. Install your library inside the environment
pip install pygame-ce
```

### Run

```
python main.py
```
